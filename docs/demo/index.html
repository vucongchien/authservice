Chưa kết nối

📧 1. Luồng Magic Link

Đăng nhập không cần mật khẩu. Chỉ nhận POST /verify để chống bot email.

Sẵn sàng. Nhập email và nhấn "Gửi Magic Link".

🌐 2. Luồng Google OAuth 2.1

Client gửi Google ID Token lên server để tự động Account Linking (1 Email = 1 User ID).

Nhấn "Đăng nhập Google" để kiểm tra ghép nối tài khoản.
